Research Foundation
🤖

Vision-Language Models & CLIP

Radford et al. (2021) introduced CLIP, learning joint image-text representations via contrastive learning on 400M image-caption pairs, enabling zero-shot classification and cross-modal alignment. Works like ALIGN and FLAVA extended this with larger datasets.

🖼️

Image Authenticity & Deepfake Detection

FaceForensics++ demonstrated CNN-based models effectively detect manipulated images. Frequency-domain FFT analysis (Qian et al.) reveals hidden artifacts in AI-generated images invisible in the spatial domain. Hybrid CNN + forensic approaches improve robustness.

📝

AI-Generated Text Detection

With the rise of LLMs, distinguishing human-written from AI-generated text has become critical. Stylometric features, perplexity scoring, and fine-tuned classifiers have been explored to detect synthetic content across news, social media, and academic writing.

🧠

Explainable AI in Multimodal Systems

Selvaraju et al. introduced Grad-CAM, generating visual heatmaps highlighting decision-influencing image regions. Combined with attention visualization in multimodal contexts, it provides interpretable explanations for image-text match or mismatch decisions.

🔒

Privacy-Preserving AI Pipelines

Differential Privacy, Federated Learning, and PII anonymisation protect multi-agent AI pipelines. Dictionary-based UUID masking offers a deterministic, low-latency approach to GDPR-compliant data minimisation in real-time social media analysis systems.

📰

Multimodal Misinformation Detection

Zlatkova et al. and Nakamura et al. showed false claims frequently pair real images with misleading captions. The NewsCLIPpings dataset (Luo et al., 2021) addresses out-of-context image-text pairs, a key challenge in real-world fake news verification.

01

No Architecture-Level Privacy Enforcement

Existing multi-agent misinformation detection systems transmit raw user identity data across agents without anonymisation, violating GDPR data minimisation principles. No lightweight, real-time solution enforces consistent privacy across agent boundaries.

02

Lack of Explainability in Similarity Models

Most multimodal similarity models output only a score or binary label with no mechanism explaining which visual concepts or semantic categories drove the decision, limiting user trust and making model debugging difficult in production systems.

03

Embedded Text Ignored in Image Analysis

Existing CLIP-based systems process image pixels but discard embedded text within images such as signs, overlaid captions, and meme text. This significantly reduces accuracy in social media contexts where embedded text carries critical semantic meaning.

04

Siloed Detection Components

Text analysis, image forensics, and cross-modal systems operate independently with no unified pipeline. There is a lack of cohesive multi-agent systems that combine classical ML, deep learning, knowledge retrieval, and live evidence validation into one framework.

05

Limited Generalization to Real-World Data

Most research prototypes are evaluated on controlled benchmark datasets. Models trained on static datasets decline against novel generative techniques and real-world social media data that is dynamic, noisy, and diverse in format and quality.

Core Research Challenge

How can a privacy-preserving, multi-agent AI framework be designed to accurately detect misinformation across text, images, and multimodal social media content — providing interpretable explanations — without compromising user privacy or real-time performance?

🔐

Privacy Preservation

Raw user identity data travels unprotected through multi-agent pipelines, creating compositional privacy leakage risk and violating GDPR data minimisation requirements at every agent handoff.

📝

AI-Generated Text Detection

The rise of LLMs makes it increasingly difficult to distinguish human-written from AI-generated content. Existing approaches lack ensemble robustness and real-time integration with external evidence sources.

🖼️

Image Authenticity Detection

Modern GANs and diffusion models generate synthetic images nearly indistinguishable from real photographs. CNN-only approaches lack interpretability and generalize poorly to unseen generative techniques.

🔗

Image-Text Alignment

False stories frequently pair accurate images with misleading captions. Detecting out-of-context misalignment requires explainable cross-modal analysis at the concept, category, and visual saliency level.

✓

Privacy Gateway: Design a PII Agent using dictionary-based UUID masking as a mandatory privacy gateway before any analytical processing begins, achieving 100% masking accuracy with under 5ms overhead per request.

✓

Multi-Agent Orchestration: Develop a CrewAI Flow-based orchestration layer routing anonymised content to appropriate agents based on content modality — text, image, or multimodal — with conditional routing and state management.

✓

AI-Generated Text Detection: Build a classifier to detect whether a given piece of text is human-written or AI-generated, using stylometric features and language model-based approaches for robust real-world detection.

✓

Hierarchical Image CNN: Design a two-stage hierarchical CNN classifying images as Real vs AI-Generated, and further as Natural vs Digitally Edited, using TensorFlow/Keras on 165,782 images achieving approximately 85% accuracy.

✓

Hybrid Forensic Analysis: Integrate texture analysis, edge detection, colour distribution analysis, and FFT frequency-domain analysis alongside CNN classification for a score-fused final prediction with improved interpretability.

✓

CLIP Similarity Engine: Build a CLIP (ViT-B/32) pipeline computing cosine similarity between image and text embeddings with concept extraction across 5 semantic categories and OCR integration for embedded text.

✓

XAI Dashboard: Integrate Grad-CAM visual explanations and deploy a 4-panel interactive dashboard presenting similarity scores, concept rankings, category distributions, and human-readable decision explanations.

✓

Unified System Evaluation: Evaluate all components using Accuracy, Precision, Recall, F1-Score, and AUC-ROC, validating end-to-end system performance on real-world social media content.

1

Privacy Gateway — PII Agent

Raw JSON social media payloads are intercepted at the FastAPI boundary. The PII Agent applies dictionary-based UUID masking to all sensitive metadata fields (username, name, location, profile image), persists identity mappings to a restricted MongoDB collection, and forwards sanitised payloads — adding under 5ms overhead with 100% masking accuracy.

2

CrewAI Flow-Based Orchestration

The orchestration layer determines content modality and routes sanitised payloads conditionally — text-only to the Text Agent, image-only to the Image Agents, and multimodal content to all agents concurrently with output merging and state management across agent boundaries.

3

AI-Generated Text Detection

The text agent analyses incoming content to determine whether it is human-written or AI-generated, applying classification techniques based on linguistic patterns, stylometric features, and language model behaviour to identify synthetic text in social media posts and news articles.

4

Image Authenticity Detection — Two-Stage CNN

A hierarchical two-stage CNN (TensorFlow/Keras): Stage 1 classifies Real vs AI-Generated (85% accuracy, AUC 0.9239); Stage 2 sub-classifies Natural vs Digitally Edited. Complemented by hybrid forensic analysis (texture, edge, colour, FFT) for weighted score fusion and interpretable output.

5

Image-Text Similarity & XAI

OpenAI CLIP (ViT-B/32) encodes image and text embeddings for cosine similarity scoring. Concept extraction spans 5 semantic categories. Pytesseract OCR extracts embedded image text. Grad-CAM hooks into the CLIP visual encoder for heatmap generation. A 4-panel XAI dashboard presents scores, concept rankings, and decision explanations.

6

Evaluation & Validation

All components are evaluated using Accuracy, Precision, Recall, F1-Score, AUC-ROC, and Confusion Matrix on held-out test sets. PII Agent adds under 5ms overhead. Image CNN achieves 85% accuracy. Similarity engine targets 80–90% match/mismatch detection accuracy on real-world image-caption pairs.
